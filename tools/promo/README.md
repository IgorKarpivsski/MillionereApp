# Promo video (Remotion)

Vertical 1080x1920 promo for TikTok / Reels. `src/Promo.tsx` is the whole edit;
`public/` (not committed) holds the AI clips (`hook.mp4`, `pack.mp4`, `trophy.mp4`),
the narration (`vo.mp3`), and copies of app assets (icon, worlds, stickers, avatars,
sounds, music).
